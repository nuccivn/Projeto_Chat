# Chat Simples no Terminal (Python)

Este é um projeto iniciante de um sistema de chat que funciona diretamente no terminal (CLI). O objetivo foi colocar em prática os fundamentos da linguagem Python.

## 🎯 Objetivo
Criar uma interface interativa onde o usuário pode digitar seu nome e trocar mensagens que ficam armazenadas durante a execução do programa.

## 🛠️ O que eu usei:
* **Loops (`while`):** Para manter o chat aberto.
* **Listas e Dicionários:** Para salvar e organizar as mensagens.
* **Módulo `os`:** Para limpar a tela e deixar o visual organizado.
* **Condicionais (`if`):** Para criar o comando de saída "sair".

## 🚀 Como testar:
1. Tenha o Python instalado na sua máquina.
2. Baixe o arquivo `.py`.
3. Abra o terminal na pasta do arquivo e digite:
   ```bash
   python main.py
